# Homebrew tap

Installs [Headroom](https://github.com/mortennordbye/headroom) on a Mac. It picks the right build for your chip.

```bash
brew install --cask mortennordbye/tap/headroom-finance
brew upgrade --cask headroom-finance
```

The cask is updated automatically by each Headroom release.

The cask is called `headroom-finance` because Homebrew's own `headroom` cask is a different app. Don't install or upgrade plain `headroom`.
